# EzyWOWF — Ezy WOW Forever

와우 포에버(WoW Forever)용 **통합 편의 애드온**입니다. 미니맵 버튼(또는 `/이지`)으로 설정 창을 열고, 필요한 기능만 골라 켜고 끌 수 있습니다.

> **English** — EzyWOWF is an all-in-one convenience addon for *World of Warcraft: Forever*.
> The in-game UI is **Korean only**. Install it like any other addon and open the settings
> with the minimap button or `/ezy`.

## 상태

- 대상 게임: 와우 포에버 (TOC `## Interface: 120100, 16001`)
- 포에버 베타 기간에 제작자가 직접 쓰면서 만든 애드온입니다. 일부 기능은 게임 안에서 모든 상황을 확인하지 못했습니다.
- 게임 안 문구는 한국어만 지원합니다.

## 설치

1. [Releases](https://github.com/koprodev/EzyWOWF/releases)에서 최신 `EzyWOWF-vX.Y.Z.zip`을 내려받습니다.
2. 압축을 풀어 나온 `EzyWOWF` 폴더를 게임 설치 폴더의 `Interface\AddOns\` 안에 넣습니다.
   최종 경로가 `...\Interface\AddOns\EzyWOWF\EzyWOWF.toc`여야 합니다.
3. 게임을 완전히 껐다 켠 뒤, 캐릭터 선택 화면의 **애드온** 목록에서 EzyWOWF가 켜져 있는지 확인합니다.

> 초록색 **Code → Download ZIP**으로 받으면 폴더 이름이 `EzyWOWF-main`이 됩니다.
> 이때는 폴더 이름을 `EzyWOWF`로 바꿔야 게임이 인식합니다.

업데이트할 때는 기존 `EzyWOWF` 폴더를 새 폴더로 바꾸면 됩니다. 설정은 `WTF` 폴더에 따로 저장되어 그대로 남습니다.

지울 때는 먼저 `/이지` > 퀘스트 > 지역 퀘스트만 표시의 **사용**을 끄고, 이 기능을 쓴 캐릭터마다 한 번씩 접속한 뒤 폴더를 지우세요. 그래야 목표 창에서 뺀 다른 지역 퀘스트가 다시 추적됩니다. 설정은 와우 계정마다 따로 저장되므로, 여러 계정에서 썼다면 계정마다 끄세요.

## 사용법

- 미니맵 버튼을 누르거나 채팅창에 `/이지`(또는 `/ezy`)를 입력하면 설정 창이 열립니다.
- 설정 창은 게임 기본 금색 프레임·탭·체크박스·슬라이더 자산과 노란 옵션 글자를 사용합니다. 배경은 게임 화면이 살짝 비치는 반투명입니다.
- 창 위쪽 제목 표시줄을 마우스 왼쪽 버튼으로 끌면 이동하며, 놓은 위치는 다음에 열 때도 유지됩니다.
- 왼쪽에서 최상위 메뉴(일반·자동화·퀘스트 등)를 고르고, 오른쪽 상단의 기능 탭에서 옵션을 설정합니다. 탭이 많으면 다음 줄에 이어서 표시됩니다. 설정을 바꾼 뒤 아래쪽 **[저장]** 을 누르면 적용됩니다.
- 오른쪽 위 검색창에서 옵션 이름·설명·선택 목록·메뉴 경로를 검색할 수 있습니다. 여러 단어를 띄어 쓰면 모두 포함하는 항목을 찾습니다. 영어는 대소문자를 구분하지 않습니다.
- 검색 결과의 옵션을 누르면 해당 탭과 옵션 위치로 이동하며 강조 테두리가 표시됩니다. 메뉴 경로의 분류·기능·소그룹도 각각 누를 수 있습니다.
- 옵션으로 이동해도 검색어는 남습니다. **[검색 결과로 돌아가기]** 를 누르면 다시 결과를 볼 수 있고, 검색창에서 Enter는 첫 결과 열기, Esc 또는 ×는 검색 지우기입니다.
- 단축키가 필요한 기능은 각 기능 페이지에서 바로 지정할 수 있습니다.
- **화면 정보 > 내 상태 막대**는 선택한 적 이름표 아래에 내 체력·현재 자원·연계 점수를 보여 줍니다. 현재 자원 색은 **분노 빨강·기력 노랑·마나 파랑**입니다. 드루이드가 **곰·광포한 곰**으로 변신하면 맨 아래에 남은 마나를 파란 막대로 추가합니다. **[곰 변신 중 남은 마나]** 는 기본 켜짐이며 체크를 해제하면 추가 줄을 숨깁니다. 인간형·표범·이동 변신·바다표범·달빛야수에서는 추가 마나 줄을 표시하지 않습니다. 표범 변신 중 마나는 **드루이드 > 초상화 마나 막대**에서 확인합니다.
- **화면 정보 > 경험치 통계**는 기본 켜짐입니다. 캐릭터마다 얻은 경험치를 **몹 처치(휴식 보너스 포함)·퀘스트·탐험·기타**로 나눠 이번 접속·오늘·레벨별·누적으로 셉니다. 양은 경험치 바가 늘어난 만큼이라 합계는 항상 바와 같고, 출처는 퀘스트 완료·몹 처치·지역 발견 메시지로 고릅니다. 메시지로 알 수 없는 경험치는 기타입니다.
- 경험치 패널에는 시간당 경험치(이번 접속·최근 N분), 레벨업까지 남은 시간과 몹·퀘스트 수, 이번 접속 출처 비율이 보입니다. 정보 막대 끝에도 시간당 경험치가 붙으며, 패널이나 정보 막대에 마우스를 올리면 요약이 보이고 클릭하면 상세 통계 창이 열립니다. 만렙이거나 경험치를 잠그면 기록을 멈추고 둘 다 숨깁니다.
- 상세 통계 창(`/경험치`, 단축키 지정 가능)은 **요약**(출처별 표·최근 7일), **레벨 기록**(레벨마다 활동 시간·실제 플레이 시간·출처 비율·처치·퀘스트·주요 지역), **지역·몹·퀘스트**(지역별 시간당 경험치, 최근 레벨에서 잡은 몹의 평균 경험치 순위, 최근 퀘스트 경험치), **캐릭터 비교**(같은 계정 캐릭터의 레벨·누적 경험치·시간당·플레이 시간) 탭으로 나뉩니다.
- 시간은 접속해 있는 동안 세며, 자리 비움(AFK) 시간은 기본으로 뺍니다. 레벨별 실제 플레이 시간은 `/played`를 받은 레벨만 나오고, **[접속할 때 플레이 시간 받아 오기]** 를 켜면 접속 때마다 채팅창에 플레이 시간 메시지가 한 번 찍힙니다(기본 꺼짐). 설치한 뒤부터 세므로 그 전에 시작한 레벨은 '설치 후부터'로 표시합니다. 다른 와우 계정 캐릭터는 비교에 나오지 않습니다. 통계는 설정 내보내기(`EZY1:`)에 들어가지 않습니다.
- **드루이드 > 초상화 마나 막대**는 기본 켜짐입니다. 곰·광포한 곰·표범으로 변신하면 기본 플레이어 프레임(내 초상화 오른쪽)의 체력·분노/기력 막대 아래에 남은 마나를 파란 막대로 붙입니다. 프레임 테두리는 게임이 보조 자원 막대에 쓰는 3단 모양으로 바뀌고, 인간형·이동 변신·바다표범·달빛야수처럼 마나를 쓰는 모습이 되면 원래 프레임으로 돌아갑니다. 막대 글자는 게임 설정의 상태 텍스트(숫자·백분율·둘 다)를 따르며, 상태 텍스트를 끄면 막대에 마우스를 올렸을 때만 보입니다. 막대를 클릭하면 플레이어 프레임을 클릭한 것과 같습니다.
- **드루이드 > 자원·변신 패널**은 원하는 경우 따로 켜는 독립 패널이며 기본 꺼짐입니다. 대상 이름표 없이 체력·현재 자원을 보여 주고, 곰·표범의 남은 마나와 표범의 연계 점수도 선택해 표시할 수 있습니다. 표시할 줄·전투 중만 표시·크기·위치를 설정할 수 있습니다. 통합 표시를 처음 적용할 때 기존 독립 패널도 한 번 꺼집니다. 필요하면 **[사용]** 을 다시 켜세요. 이후 선택과 기존 위치를 유지합니다.
- **드루이드 > 정신집중 발동 알림**은 청명의 전조가 발동할 때 아이콘과 소리를 표시합니다. 남은 시간은 게임이 제공하는 타이머를 사용합니다. 버프 정보가 제한되면 허용된 발동 표시로 확인하고, 확인할 수 없는 동안에는 숨깁니다. 청명의 전조 자체는 지속 버프 누락 경고에서 제외합니다.
- **화면 정보 > 쿨다운 표시**에서 드루이드의 정신 자극·환생·나무 껍질·질주 고정 아이콘을 각각 켜고 끌 수 있습니다. 배운 기술만 표시하며, 밝은 준비·자원 부족·사용 불가·쿨다운 상태를 구분합니다. 대상·거리·환생 재료는 게임에서 별도로 확인하세요.
- **일반 > 직업 매크로**의 드루이드 목록에서 독·저주 해제, 정신 자극, 환생, 나무 껍질·질주 매크로를 만들 수 있습니다. 시전은 직접 눌러 실행합니다. **기본 공격**은 곰이면 후려치기, 표범이면 할퀴기, 변신하지 않았으면 곰 변신이고, Shift를 누르면 변신을 풀고 천벌을 시전합니다(달빛야수는 변신을 유지하고 천벌). 매크로는 거리를 판단하지 못하므로 가까우면 그냥, 멀면 Shift로 누르세요. **돌진 섬광**은 곰·표범이면 야성의 돌진, 인간형·달빛야수면 달빛 섬광을 시전하고 이동·바다표범 변신에서는 아무것도 하지 않습니다. 게임 설정에서 Shift가 주시 대상 시전 키이면 Shift 매크로가 주시 대상에게 시전되니 그 키를 바꾸세요. 변신 슬롯 번호를 사용하는 매크로는 변신을 새로 배웠을 때 다시 만드세요.
- **화면 정보 > 사거리 표시**는 드루이드 곰의 후려치기·표범의 할퀴기·인간형과 달빛야수의 천벌을 기준으로 바뀝니다. 이동·바다표범 등 다른 변신에서는 원래 이름표로 복원합니다.
- **지도·길찾기 > 지역 레벨**은 기본 켜짐입니다. 세계 지도(M)에서 대륙을 선택하면 지역별 범위를 볼 수 있고, 지역 지도에서는 왼쪽 위에 범위를 고정 표시합니다. 게임 지도 정보, 퀘스트·지역 파티 찾기의 추천 레벨, 클래식 참고 범위 순으로 사용합니다. 클래식 참고값은 게임의 별도 추천 정보가 없을 때만 사용하며, 대도시·지원하지 않는 지역은 생략합니다. 내 레벨이 범위보다 낮으면 빨강, 범위 안이면 초록, 높으면 회색입니다. 글자 크기 자동 조절은 기본 켜짐이며, 대륙 지도 창 크기·확대 비율에 맞춰 기준 크기를 8부터 설정 크기까지 조절합니다. 지역 이름은 조절된 기준 크기의 80%, 레벨 숫자는 70%로 표시합니다. 범위는 `8~24`, 단일 레벨은 `60`처럼 숫자만 표시합니다. 지역 지도 왼쪽 위 표시는 창 크기에만 맞추고 확대·이동 중에는 고정됩니다. 기본 기준 크기는 12이며, 설정에서 자동 조절을 끄거나 기준 크기(8~24)를 바꿀 수 있습니다.
- 클래식 지역 레벨 참고값은 [LibTouristClassic WoW-1.13.5-release1](https://www.wowace.com/projects/libtourist-classic/files/3033418)의 야외 지역 자료를 사용합니다. 포에버에서 별도로 조정한 값은 아니며 게임이 추천 범위를 제공하면 그 값을 우선합니다.
- 미니맵 왼쪽의 **전문가 찾기 아이콘**을 클릭하면 작은 찾기 패널이 열리고, 다시 클릭하면 닫힙니다. 세계 지도(M)에서도 오른쪽 위 **[전문가 찾기]** 버튼으로 같은 패널을 열 수 있습니다. 패널 제목의 **[접기] / [펼치기]** 로 크기를 줄이거나 다시 펼칠 수 있고, × 또는 Esc로 닫습니다.
- 찾을 직업·전문 기술을 여러 개 체크하면 세계 지도에 함께 표시됩니다. 체크 목록 아래쪽의 **직업용품 / 일용품 / 마법 재료**는 해당 상인을 표시합니다. 상인은 **[전체]** 에는 포함되지만, 설정의 전문가 종류 **[모든 전문 기술]** 에는 포함되지 않습니다. 미니맵에도 현재 주변의 전문가를 **작은 빨간 점**으로 표시하며, 마우스를 올리면 이름과 역할을 볼 수 있습니다. 이동·확대·회전·네모/원형 모양에 맞춰 위치가 바뀌고, 미니맵 범위 밖의 전문가는 숨깁니다. **[내 직업] / [전체] / [모두 해제]** 로 한 번에 바꿀 수 있고, 선택은 즉시 저장되어 다음 접속에도 유지됩니다. 미니맵·지도·설정 창은 같은 선택을 공유합니다. 지도 패널을 열거나 지도를 바꾸면 해당 지역의 전문가 목록을 보여 줍니다. 지역·NPC를 골라 하단의 **[지도에서 찾기]** 또는 지도 아이콘을 클릭하면 지도 핀과 길 안내를 시작합니다.
- **지도·길찾기 > 기술·직업 전문가 찾기**(또는 `/전문가`, `/trainers`)에서 아이콘·지도 버튼 표시 여부, 미니맵 점 표시(기본 켜짐)·크기(기본 6, 4~10), 내 진영·중립 전문가만 표시(기본 켜짐), 지도 아이콘 크기를 설정할 수 있습니다. 기본 종류는 내 직업입니다. 참고 위치이므로 포에버의 실제 위치와 가르치는 기술·등급, 상인이 파는 물건은 다를 수 있으며, 기술을 배울 수 있는지까지 판정하지는 않습니다.
- 전문가 위치는 [QuestieDB의 포에버 자료](https://github.com/Questie/QuestieDB/tree/e0a6eaa86f181ac99262e34126bcd2ed1a1712d6)에서 NPC 이름·역할·진영·좌표 사실을 자체 형식으로 추출했습니다. 좌표 보정 기준은 포에버 빌드 `1.60.1.69893`이며, 원래 NPC의 세계 위치가 유지된다는 가정이 포함되어 있습니다. 마을별 목록은 지역 지도에서 확인하며, 전문가가 없는 마을이나 자료에 없는 NPC는 표시하지 않습니다.
- 스카이본 시작 지역 **제프라스 섬**은 QuestieDB에 NPC 자료가 없어, [warcraft.wiki.gg](https://warcraft.wiki.gg/wiki/Zephras_Isle)의 NPC 문서(판 번호 고정, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/))에서 직업 전문가와 연금술·요리·응급치료 전문가 12명의 위치를 가져왔습니다. 위키 이름은 영어라 게임에서 NPC 번호로 한국어 이름을 받아 표시하며, 받지 못하면 영어 이름을 씁니다. 위키에 없는 다른 전문 기술 전문가와 상인은 표시하지 않습니다.
- **직업기술 > 낚시**(또는 `/낚시`, `/fishing`)에서 낚싯대와 미끼 1~3순위를 고른 뒤 **[저장] → [패널 열기] → [장착]** 순서로 시작합니다. 가방에서 낚싯대를 직접 장착해도 패널이 나타납니다. 낚시·건지기·미끼·장착·복원 버튼을 사용하며, 찌를 던지는 키와 게임의 상호작용 키를 따로 지정할 수 있습니다. 입질이 오면 **[건지기]** 아이콘을 클릭하거나 상호작용 키·찌 클릭으로 건져 올립니다. 상호작용 키는 일반 NPC·물건 조작과 공유합니다.
- **[건지기]** 는 낚시 중 아이콘 위에서 마우스 왼쪽 클릭을 게임의 기본 상호작용으로 연결합니다. 툴팁에는 현재 상호작용 키가 표시되며, 키를 바꿔도 같은 상호작용 명령을 사용합니다. 커서를 떼거나 낚시가 끝나면 원래 마우스 입력으로 돌아가며 기존 단축키를 바꾸지 않습니다. 마우스 입력 연결을 확인하지 못하면 아이콘이 흐려집니다. 클릭이 반응하지 않거나 이 게임 버전에서 마우스 상호작용을 지원하지 않으면 지정한 상호작용 키를 사용하고 `/낚시 진단`으로 연결 상태를 확인하세요.
- 낚싯대를 장착하거나 낚시 중일 때 작은 상태 패널이 나타납니다. **[위치 이동]** 으로 미리 보고 제목을 드래그할 수 있으며, 패널·버튼 크기도 조절할 수 있습니다. 패널에는 숙련도·일반 가방의 빈칸·미끼 개수·남은 시간과 준비 경고가 표시됩니다. 일반 무기의 주무기·보조무기를 캐릭터별로 기억하므로 가방에서 낚싯대로 바꾼 경우와 재접속 후에도 **[복원]** 을 누를 수 있습니다. 복원할 무기 이름도 패널에 표시되며, 장착·복원에 실패하거나 장비 변경이 늦게 반영되면 기록을 유지합니다. 빈 장비칸 복원에는 일반 가방의 빈칸이 필요하며, 기능을 끄기 전에 무기를 복원하세요. 처음부터 낚싯대를 장착했고 이전 무기 기록이 없다면 원래 무기를 알 수 없으므로 일반 무기를 한 번 장착한 뒤 낚싯대로 바꿔 주세요.
- 패널에는 지금 장착한 낚싯대 이름이 표시되며 장비를 바꾸면 갱신됩니다. 숙련도 한도에 도달해도 낚시는 계속 사용할 수 있습니다. 실행할 수 없는 버튼은 마우스를 올리거나 클릭하면 이유를 안내합니다. 입력이 반응하지 않을 때는 **[상태 진단]** 또는 `/낚시 진단`으로 찌 던지기·상호작용 키 연결, 시전 가능 상태·단축키 버튼 입력 수신 횟수, 건지기 아이콘의 마우스 진입·포커스·클릭 연결 상태를 확인할 수 있습니다.
- 미끼는 지원하는 클래식 낚시 미끼 중 가방에 있는 것을 등록하고 우선순위대로 선택합니다. 이름은 게임의 아이템 정보를 사용하며, 사용 중인 낚싯대에 임시 강화가 남아 있으면 덮어쓰지 않습니다. 숙련도·시간을 게임이 제공하지 않으면 확인 불가로 표시합니다. 요구 숙련·사용 가능 여부는 게임의 아이템 제한을 따릅니다.
- 낚시 중 찌 상호작용 범위·아이콘 설정은 시전 종료 시 복원됩니다. **[낚시 중 소리 크기 바꾸기]** 는 효과음·음악·환경음을 바꾸고 **[마치기]** 또는 무기 복원, 전투·죽음·지역 이동·접속 종료 시 되돌립니다. 소리 강조는 다른 효과음에도 적용됩니다. 사용 중 직접 바꾼 게임 설정은 유지합니다. 기존 **빠른 설정**의 낚시 항목은 이 탭으로 옮겼으며, 자동 범위 확대의 기존 선택을 가져옵니다. **[낚시 전문가 찾기]** 와 **[빠른 자동 루팅 설정]** 으로 기존 기능을 열 수 있습니다.
- **준비 상태 알림**에서 새로 생긴 미끼 만료·미적용·부족, 가방 빈칸 부족, 숙련 한도 등의 경고를 채팅으로 표시합니다. 소리 알림은 별도로 켤 수 있습니다. 같은 경고를 매초 반복하지 않으며, 미끼를 다시 바르거나 가방을 비워 해결한 뒤 같은 조건이 생기면 다시 알립니다. 정보 확인 불가·전투·죽음 중에는 새 알림을 보류합니다.
- **이번 낚시 기록**에는 낚시 시간·던진 횟수·건진 횟수와 획득 아이템을 표시합니다. **[낚시 패널에 이번 기록 요약 표시]** 를 켜면 낚시 중에도 별도 통계 영역에서 시간·횟수·획득량을 매초 확인할 수 있습니다. 긴 무기 이름·경고·통계는 줄바꿈하고 필요한 높이를 확보해 버튼과 겹치지 않게 표시합니다. 첫 시전부터 시간을 세고 전투·죽음·지역 이동·접속 종료 중에는 멈춥니다. 기록은 캐릭터별로 남으며, **[마치기]** 또는 **[복원]** 후 다음 시전부터 새 기록을 시작합니다. **[이번 기록 초기화]** 는 이번 기록만 비웁니다. 획득은 게임이 낚시 전리품이라고 확인한 아이템의 슬롯이 비워질 때 집계하므로, 줍지 않고 창을 닫은 아이템은 포함하지 않습니다. 게임이 낚시 전리품 정보를 제공하지 않으면 획득 집계를 생략하며, 목록은 최대 5종과 나머지 종류 수를 표시합니다.
- 퀘스트 몹의 개인 징표는 내 화면의 적 이름표에만 표시됩니다(V로 이름표 켜기). 공유를 켜야 파티원에게 보이는 게임 징표를 붙입니다. 공유를 꺼도 이전 게임 징표는 자동으로 지우지 않습니다.
- 개인 징표 표시는 게임의 매크로 스크립트(/run) 실행이 필요합니다.
- 게임이 단축키 매크로를 255바이트까지만 읽기 때문에, 퀘스트 몹 대상 키에는 가까운 퀘스트의 몹부터 들어가는 만큼만 넣습니다(한글 이름은 보통 2~3마리). 들어간 몹은 설정의 **[몹 목록 보기]** 로 확인할 수 있습니다.
- 전투 중 선택한 퀘스트를 바꾸면 대상 키는 전투가 끝난 뒤 갱신됩니다.
- 수집 퀘스트의 몹은 이름표에 보이거나 마우스를 올렸을 때 툴팁에서 알아냅니다. 필요한 수량을 모두 모으면 대상에서 제외합니다.
- 체력 100%인 몹만 고르는 필터와 선택한 몹을 향한 방향·거리 안내는 제공하지 않습니다. 시체는 대상에서 제외합니다.
- **자동화 > 잡템 판매·자동 수리**는 상인 창을 열면 게임의 **모든 잡동사니 아이템 판매**로 회색 아이템을 한 번에 팔고, 실제로 가방에서 빠진 개수와 금액을 채팅창에 알립니다. **판매 잠금**: 가방 창 왼쪽 위 아이콘을 누르고(합친 가방이면 가방 이름을 고른 뒤) **이 가방 무시**의 **[잡동사니 판매]**에 체크하면 그 가방의 회색 아이템은 팔지 않고, 같은 자리를 다시 눌러 체크를 풀면 다시 팝니다.
- **툴팁·아이템 > 싼 아이템 정리**는 기본 켜짐입니다. 가방에서 판매가 합계(개당 가격 × 개수)가 가장 싼 칸(기본 4칸)에 빨간 테두리와 순위 숫자를 띄우고, 툴팁에도 순위와 판매가를 적습니다. 가방 창의 **정리** 버튼을 누르면 게임 정리가 끝난 뒤 그 아이템을 맨 아랫줄 왼쪽부터 싼 순서로 모읍니다. 그동안 아이템을 집어 들면 멈춥니다. 가방 창 왼쪽 바깥, 정리 버튼 높이의 **빨간 X(삭제) 버튼**을 누를 때마다 1위 아이템 한 칸을 지우고 채팅창에 지운 아이템을 알립니다. 버튼에 마우스를 올리면 다음에 지울 아이템이 보이며, 지운 아이템은 되돌릴 수 없습니다.
- 순위에는 기본으로 회색·흰색 아이템만 넣고(설정에서 회색만 가능), 판매가가 없거나 팔 수 없는 아이템·퀘스트 아이템·퀘스트 목표에 이름이 나오는 아이템·아직 열지 않은 상자는 넣지 않습니다. **잠금**: 가방 창 왼쪽 위 아이콘을 누르고(합친 가방이면 가방 이름을 고른 뒤) **이 가방 무시**의 **[정리]**에 체크하면 그 가방의 아이템은 순위·삭제·맨 아랫줄 모으기에서 빠지고, 같은 자리를 다시 눌러 체크를 풀면 다시 들어갑니다. **[전문 기술 재료 빼기]**(기본 켜짐)는 옷감·가죽·광물·약초·고기처럼 직업용품으로 분류된 아이템을 뺍니다. 게임이 애드온의 아이템 삭제를 마우스·키 입력 한 번에 한 칸으로 제한하므로 자동으로 연달아 지우지는 않습니다.

## 명령어

| 명령 | 설명 |
|---|---|
| `/이지`, `/ezy` | 설정 창 열기/닫기 |
| `/퀘템`, `/qik` | 퀘스트 아이템 설정 열기 (`list`·`next`·`auto`·`move`) |
| `/way`, `/좌표` | 좌표 길 안내. 예: `/way 45.2 63.1`, `/way 서부 몰락지대 45 63`, `/way 지우기` |
| `/메모`, `/memo` | 메모 창 열기/닫기. `/메모 <글>`은 메모 맨 끝에 한 줄을 덧붙입니다 |
| `/경험치`, `/xpstats` | 경험치 통계 창 열기/닫기 |
| `/전문가`, `/trainers` | 기술·직업 전문가 찾기 열기 |
| `/낚시`, `/fishing` | 직업기술 > 낚시 설정 열기 |
| `/낚시 진단`, `/fishing debug` | 낚시 단축키·시전 상태·장착 무기 확인 |

## 설정 저장과 백업

- 설정은 게임을 끄거나 `/reload` 할 때 `WTF\Account\<계정>\SavedVariables\EzyWOWF.lua`에 기록됩니다.
- 포에버 베타에서 애드온 설정과 단축키가 초기화되는 사례가 있어서, **일반 > 설정 백업**에서 설정을 글자 한 줄(`EZY1:`로 시작)로 내보내 두었다가 다시 가져올 수 있습니다.
- 채집·보물 기록(`EZYN1:`)과 캐릭터 설정 복사(`EZYC1:`)도 같은 방식으로 옮길 수 있습니다.
- 메모 글도 같은 저장 파일에 들어가서, 같은 계정의 모든 캐릭터가 같은 메모를 봅니다. 설정 내보내기(`EZY1:`)에는 들어가지 않으니, 다른 계정으로 옮길 때는 메모 창의 **[모두 선택]** 을 누르고 복사해서 붙여 넣으세요.
- 캐릭터 설정 복사 목록에는 같은 계정 캐릭터가 저절로 올라옵니다. 애드온은 다른 계정의 저장 파일을 읽을 수 없어서, 다른 계정 캐릭터는 그 캐릭터에서 내보낸 `EZYC1:` 글자를 **[목록에 추가]** 에 붙여 넣어 올립니다. 한 번 올리면 이 계정의 모든 캐릭터가 목록에서 고를 수 있습니다.
